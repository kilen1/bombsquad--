# Расширение системы тарифов

## Описание изменений

Была расширена система тарифов для возможности настройки следующих параметров через базу данных:

1. **Описание тарифа** (`description`) - текстовое поле с подробным описанием тарифа
2. **Мод** (`mod`) - название мода, связанного с тарифом
3. **Текст кнопки подтверждения** (`confirmation_button_text`) - настраиваемый текст кнопки при подтверждении покупки
4. **Дополнительные возможности** (`additional_features`) - дополнительные характеристики тарифа
5. **Список возможностей** (`features_list`) - JSON или текстовый список возможностей тарифа

## Изменения в структуре базы данных

Добавлены следующие поля в таблицу `tariffs`:

```sql
ALTER TABLE tariffs ADD COLUMN description TEXT;
ALTER TABLE tariffs ADD COLUMN mod VARCHAR(255);
ALTER TABLE tariffs ADD COLUMN confirmation_button_text VARCHAR(255) DEFAULT 'Подтвердить покупку';
ALTER TABLE tariffs ADD COLUMN additional_features TEXT;
ALTER TABLE tariffs ADD COLUMN features_list TEXT;
```

## Обновленные файлы

1. `extend_tariff_system.php` - скрипт для обновления структуры базы данных
2. `extended_order_game.php` - обновленная версия скрипта оформления заказа с использованием новых полей
3. `extended_setting.php` - обновленный интерфейс с отображением новых параметров тарифов

## Как настроить тарифы

### Через SQL-запросы

Пример добавления описания и мода к существующему тарифу:

```sql
UPDATE tariffs 
SET 
    description = 'Премиум тариф с увеличенным количеством слотов и дополнительными возможностями.',
    mod = 'AdvancedPack',
    confirmation_button_text = 'Купить сейчас',
    features_list = '["100 игровых слотов", "Приоритетная поддержка", "Эксклюзивные скины", "Резервное копирование"]'
WHERE id = 1;
```

### Формат features_list

Поле `features_list` может содержать:
- JSON-массив: `["возможность1", "возможность2", ...]`
- Текст с переносами строк: 
```
возможность1
возможность2
```
- Текст с разделителями точкой с запятой: `возможность1; возможность2;`

## Возможности интерфейса

### Отображение описания тарифа
- В модальном окне при выборе тарифа теперь отображается его описание
- Если описание отсутствует, блок не показывается

### Отображение мода
- Рядом с названием тарифа отображается указанный мод
- Если мод не задан, соответствующий элемент не отображается

### Настраиваемая кнопка подтверждения
- Текст кнопки "Подтвердить покупку" теперь берется из поля `confirmation_button_text`
- По умолчанию используется "Подтвердить покупку"

## Совместимость

- Все новые поля являются необязательными (nullable или с дефолтным значением)
- Старые тарифы продолжат работать без изменений
- Если поля не заполнены, используются значения по умолчанию

## Примеры использования

### Пример 1: Тариф с модом и специальной кнопкой
```sql
UPDATE tariffs 
SET 
    description = 'Эксклюзивный тариф с модом RPG Pack',
    mod = 'RPG Pack',
    confirmation_button_text = 'Начать приключение!',
    features_list = '["Специальные персонажи", "Уникальные локации", "RPG механики"]'
WHERE name = 'RPG Premium';
```

### Пример 2: Бесплатный тариф с подробным описанием
```sql
UPDATE tariffs 
SET 
    description = 'Базовый тариф для начала игры. Подходит для новичков.',
    confirmation_button_text = 'Попробовать бесплатно',
    features_list = '["10 игровых слотов", "Базовая карта", "Стандартные персонажи"]'
WHERE name = 'Free Basic';
```

## API изменения

В ответе от `order_game.php` теперь возвращаются дополнительные данные о тарифе:

```json
{
  "success": true,
  "tariff_info": {
    "name": "Название тарифа",
    "description": "Описание тарифа",
    "mod": "Название мода",
    "confirmation_button_text": "Текст кнопки",
    "additional_features": "Дополнительные возможности",
    "features_list": "Список возможностей"
  }
}
```

## Безопасность

- Все новые поля проходят экранирование при выводе в интерфейсе
- Используется безопасный SQL с подготовленными выражениями
- Все пользовательские данные обрабатываются корректно
